
# Student Management System

## Project Description
A Python-based application designed to manage student records easily.

## Features
- Add student details
- Display all students
- Search students by roll number
- Update student information
- Delete student records
- Store records permanently using JSON

## Technologies Used
- Python 3
- JSON
- File Handling

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: python main.py
